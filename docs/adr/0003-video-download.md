# Download videos as direct MP4 files

Pixiegrabber downloads videos as direct MP4 files from the verified Mux renditions that Pixieset already serves. It does no HLS, ffmpeg, or remuxing: the `video_source` token that Mux mints at API-call time also authorizes the `high.mp4`, `medium.mp4`, and `low.mp4` static renditions on `stream.mux.com`, so a video is one plain GET with Range support. Video download is opt-in behind `--videos`, and video URLs are transient and never persisted. Mux serves videos at up to 1080p and its signed URLs live 24 hours, so a very long discovery pass can outlive its own video links; a `403` on a video therefore maps to a distinct "expired link, run again" failure instead of an authentication error. A video record that cannot be parsed stops the run with the sanitized diagnostic, keeping the fail-closed rule that an unreadable video is never silently dropped. A video that is well-formed but has no usable source becomes a Reference with presence state missing and no Placement, and the run still exits zero.
